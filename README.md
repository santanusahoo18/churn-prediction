# Customer Churn Prediction

A machine learning web application that predicts whether a telecom customer is likely to churn based on customer information and service details.

## Project Overview

Customer churn refers to customers leaving a company's services.

This project uses machine learning to analyze customer information and predict the likelihood of customer churn. The trained model is integrated with a FastAPI backend and a web-based frontend.

The project demonstrates the complete machine learning workflow:

**Data Analysis → Data Preprocessing → Model Training → Model Evaluation → Model Saving → FastAPI API → Web Interface**

## Machine Learning Workflow

### 1. Data Collection

The project uses telecom customer data containing customer demographics, account information, services and churn information.

### 2. Data Preprocessing

The data is prepared for machine learning by:

* Handling missing values
* Converting numerical columns
* Encoding categorical variables
* Selecting relevant features
* Preparing the target variable

### 3. Exploratory Data Analysis

The notebook contains analysis of customer characteristics and churn patterns.

Examples of analysis include:

* Overall churn rate
* Customer tenure
* Contract type
* Internet service
* Monthly charges
* Payment methods
* Customer demographics

### 4. Model Training

The processed data is used to train a machine learning classification model.

The trained model is saved and later loaded by the FastAPI application.

### 5. FastAPI Backend

FastAPI provides an API endpoint for making predictions.

Example endpoint:

```text
POST /predict
```

The API receives customer information and returns a churn prediction.

### 6. Web Application

The frontend provides a simple interface where users can enter customer information and receive a churn prediction.

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd churn_project
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment on Windows:

```powershell
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

Start the FastAPI server:

```bash
uvicorn app.main:app --reload
```

Open the application in your browser:

```text
http://127.0.0.1:8000
```

## API Documentation

FastAPI automatically provides interactive API documentation.

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

You can use the documentation to test the `/predict` endpoint.

## Example API Response

The API returns the prediction generated by the trained machine learning model.

Example:

```json
{
    "prediction": "No Churn"
}
```

The exact response depends on the implementation of the prediction endpoint.
